# Lexique de marque

Références opérationnelles pour la rédaction de tous les supports. À utiliser dès la phase de brief.

## Champs lexicaux à privilégier

| Champ sémantique | Vocabulaire recommandé |
|---|---|
| Apprentissage | apprendre, progresser, développer, acquérir, approfondir, consolider |
| Compétences | compétences, savoir-faire, connaissances, pratiques professionnelles |
| Réussite | évoluer, avancer, réussir, progression, accomplissement |
| Accompagnement | accompagnement, suivi pédagogique, soutien, encadrement |
| Parcours | parcours, trajectoire, projet, avenir, orientation |
| Rythme | à votre rythme, progressif, flexible, adaptable |
| Autonomie | autonomie, responsabilisation, prise d'initiative |
| Accessibilité | accessible, ouvert à tous, inclusif |
| Projection pro | insertion professionnelle, évolution professionnelle, perspectives |
| Pédagogie | pédagogie, méthodes pédagogiques, apprentissage structuré |
| Objectifs | objectifs professionnels, objectifs pédagogiques |
| Valeurs | excellence, accompagnement, innovation, accessibilité |

## Formulations conformes — promesses

| Thème | À utiliser | À éviter |
|---|---|---|
| Emploi | Peut vous aider à évoluer / Favorise l'employabilité / Vous prépare à l'exercice du métier de... | Job garanti / Emploi assuré / Embauche garantie / Placement |
| Diplôme | Vous prépare à l'obtention du diplôme / Préparation à un diplôme reconnu par l'État | Diplôme assuré / Réussite au diplôme garantie / Diplôme automatique |
| Salaire | Données salariales indicatives (avec source) / Perspectives salariales selon le poste | Augmentation garantie / Salaire garanti / Gros salaire |
| Accompagnement | Accompagnement vers la réussite / Équipe pédagogique / Suivi pédagogique | Coach personnel dédié / Mentor personnel garanti / Suivi sur-mesure garanti |
| Résultat | Développez des compétences / Progression à votre rythme / Montée en compétences progressive | Résultat immédiat / Transformation assurée / Succès rapide / Sans effort |
